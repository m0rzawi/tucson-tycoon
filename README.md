# Tucson Tycoon — MVP 0.1

Локальная PWA для учёта фарма, капитала и сделок на Arizona RP Tucson.

## Уже работает
- Главный экран: капитал, цель, прогресс.
- Калькулятор инкассаторки: базовая зарплата, бонус госработника, бонус машины, Viking, охранник, аренда и длительность.
- Сохранение фактических смен и автоматическое обновление баланса.
- Учёт собственных наблюдений цен.
- Трекер перекупа: цена покупки, продажи, расходы, ожидаемая прибыль и ROI.
- Закрытие сделки с начислением прибыли.
- История, экспорт и импорт JSON.
- PWA-манифест и service worker для установки и офлайн-режима.

## Запуск локально
Нужен Python 3:
```bash
python -m http.server 8080
```
Открой `http://localhost:8080`.

Для установки PWA на телефон нужен HTTPS (например, GitHub Pages).

## Публикация через GitHub Pages
1. Создай репозиторий `tucson-tycoon`.
2. Загрузи содержимое этой папки в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` → `/root`.
4. Открой выданный HTTPS URL на Android и выбери «Добавить на главный экран».

## Важные ограничения MVP
- Данные хранятся в localStorage текущего браузера. Между устройствами не синхронизируются.
- Интеграция ARZ-MCR пока представлена ссылкой на первоисточник и собственным журналом наблюдений. Публичная документация стороннего API ARZ-MCR не подтверждена.
- Не загружай большие неотфильтрованные массивы лавок. Для будущего коннектора нужно выяснить разрешённый способ доступа и условия использования.
- Бонусы в калькуляторе — настраиваемые предположения. Проверяй фактическую выплату в игре.
